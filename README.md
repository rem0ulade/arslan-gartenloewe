# Arslan Garten-Löwe

Responsive Website für Gartenpflege, Gartengestaltung und Landschaftsbau in Norderstedt und Hamburg-Nord.

## Lokal starten

```bash
npm install
npm run dev
```

## Veröffentlichung

Ein Push auf `main` baut die statische Website und veröffentlicht sie automatisch auf GitHub Pages.
